# Camp Dutch Oven Coal Chart

A responsive, single-page reference for how many charcoal briquettes to put on the lid and under a camp Dutch oven to hold a given temperature.

- Pick your oven size (by diameter, quarts, or liters) and temperature to get the coal count; the full chart is one tap away on phones.
- Prints as a one-page, black-and-white-friendly chart.

Open `index.html` in a browser — no build step.

Data source: Lodge Cast Iron, [How Many Coals to Use When Cooking with a Camp Dutch Oven](https://www.lodgecastiron.com/blogs/story/how-many-coals-use-when-cooking-with-a-camp-dutch-oven).
